# 🎵 Alpha Music

Alpha Music is a modern, responsive, and full-featured music streaming web application. It features a React-based frontend built with Vite and Zustand for state management, and a Node.js/Express backend integrated with MongoDB for database storage and Multer/Cloudinary for media uploads.

---

## 🚀 Features

- **User Authentication**: Secure login and signup.
- **Music Player**: Custom media player controls (Play, Pause, Skip, Volume, Seek, Queue).
- **Responsive Design**: Optimized for mobile, tablet, and desktop screens.
- **Upload Tracks**: Ability to upload new audio files and album covers.
- **Playlists & Favorites**: Create playlists and mark songs as favorites.
- **Search**: Dynamic search for tracks, artists, and albums.
